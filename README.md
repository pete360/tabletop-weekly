# Tabletop Weekly

A weekly static newsreader for tabletop games — release notes, preorders, and shipping updates with facts only.

- **Latest:** [https://pete360.github.io/tabletop-weekly/](https://pete360.github.io/tabletop-weekly/) (always the newest week)
- **Archive:** [https://pete360.github.io/tabletop-weekly/archive/](https://pete360.github.io/tabletop-weekly/archive/)

Served via GitHub Pages from `main`. Images are embedded in each HTML report.
